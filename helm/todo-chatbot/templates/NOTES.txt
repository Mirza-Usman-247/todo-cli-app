📝 Phase IV — Local Kubernetes Deployment

To access your application:

1. Start Minikube tunnel (required for LoadBalancer services):

   $ minikube tunnel

   (Keep this running in a separate terminal - requires sudo on some systems)

2. Wait for pods to be ready:

   $ kubectl get pods -n {{ .Values.global.namespace | default "todo-app" }} -w

3. Access the application:

   Frontend: http://localhost:3000
   Backend:  http://localhost:8000/health

4. Verify deployment:

   # Check pods status
   $ kubectl get pods -n {{ .Values.global.namespace | default "todo-app" }}

   # Check services
   $ kubectl get svc -n {{ .Values.global.namespace | default "todo-app" }}

   # View frontend logs
   $ kubectl logs -l app.kubernetes.io/component=frontend -n {{ .Values.global.namespace | default "todo-app" }}

   # View backend logs
   $ kubectl logs -l app.kubernetes.io/component=backend -n {{ .Values.global.namespace | default "todo-app" }}
